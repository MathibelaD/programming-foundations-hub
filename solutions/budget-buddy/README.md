# Budget Buddy reference solutions

One folder per project stage. Each is the finished code for that stage's project lesson.

**Try the stage yourself before you look here.** Comparing your version with this one afterwards is where the learning happens. Your code does not have to match: if yours works and you can explain it, it is correct.

To run a stage, copy its files into your own `budget-buddy` folder (where `prompt-sync` is installed), then run `node index.js`.
